How to test the rules (Kali VM lab)

Run these on the Kali VM, where Suricata is the detection engine. The commands send harmless local HTTP markers; Suricata decides what alerts. 

# 1. Check the lab is ready (Suricata + ports; prints fix commands)
bash scripts/start_lab.sh

# 2. Start the harmless localhost test server (separate terminal)
python3 lab/server.py --port 8000

# 3. Trigger the custom rules by hand
curl http://127.0.0.1:8000/index.html          # benign  -> no alert
curl http://127.0.0.1:8000/cyberguard-test      # trips sid 1000001
curl http://127.0.0.1:8000/cyberguard-warning   # trips sid 1000002

# 4. Run the automated end-to-end test (reads the API only)
bash scripts/e2e_test.sh

# 5. (Manual, Kali only) prove detection depends on the rule
bash scripts/rule_toggle_experiment.sh
